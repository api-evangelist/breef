# Breef

> Breef is an online agency marketplace and payments platform that connects brands with
> vetted marketing, creative, digital and web agencies. Brands scope a project, receive
> curated pitches from hand-picked agencies across 50+ project types, then run contracts,
> milestones and payments through the platform — including Breef(Pay), its
> agency-now-pay-later payment product. Founded in New York in 2019 as Curated, rebranded
> to Breef in 2021, now headquartered in Denver, with roughly 25,000 vetted agencies
> across 27 countries.

## API surface

Breef publishes **no public API**. There is no developer portal, API reference, OpenAPI or
other machine-readable contract, SDK, CLI, webhook catalog, MCP server or agent card on any
Breef host. The product is consumed through the web application at projects.breef.com by
brands and agencies; the application's own backend is authenticated and undocumented.
