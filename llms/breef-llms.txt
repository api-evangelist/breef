# Breef

> Breef is an online agency marketplace and payments platform that connects brands with
> vetted marketing, creative, digital and web agencies. Brands scope a project, receive
> curated pitches from hand-picked agencies across 50+ project types, then run contracts,
> milestones and payments through the platform — including Breef(Pay), its
> agency-now-pay-later payment product. Founded in New York in 2019 as Curated, rebranded
> to Breef in 2021, now headquartered in Denver, with roughly 25,000 vetted agencies
> across 27 countries.

## API surface

Breef publishes **no public API**. There is no developer portal, API reference, OpenAPI or
other machine-readable contract, SDK, CLI, webhook catalog, MCP server or agent card on any
Breef host. No `api.`, `developer.`, `developers.`, `docs.`, `app.` or `mcp.breef.com`
hostname resolves. The 483-URL sitemap carries no developer, API, docs or integrations page.

The product is consumed through the web application at `projects.breef.com`. That
application has a Django REST Framework backend whose router root
(`https://projects.breef.com/api/`) answers anonymously with a single route entry, and a
`drf-spectacular` OpenAPI schema endpoint at `https://projects.breef.com/api/schema/` which
negotiates `application/vnd.oai.openapi` but returns **403 Authentication credentials were
not provided** to anonymous callers. A schema therefore exists; it is not published, not
documented, and not offered as a developer product. Individual resources return 401.

There is no published rate limit, no API pricing tier, no sandbox, no status page
(`breef.statuspage.io` is an unclaimed subdomain that redirects to Atlassian marketing) and
no first-party package on npm, PyPI, RubyGems, crates.io or Packagist. The `github.com/breef`
organization is unrelated — it was created in 2014, five years before the company existed.

## Commercial terms

- Brands: free to join, scope and receive pitches; one-time **$199** placement fee on hire.
- Multiple Projects: **$499/year** for brands running 3+ agency projects a year.
- Cash back on agency spend: **3%** from $50k-$150k annually, **5%** above $150k annually.
- Agencies: free to join and pitch; **15%** referral fee on total project value for the
  first 12 months, excluding hard costs (production, media spend, influencer fees).
- Agency payouts run over direct ACH.
